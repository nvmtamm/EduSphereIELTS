# EduSphere Project Guidelines

## UI Language Standard: 100% English
- All frontend UI elements, page titles, descriptions, navigation menus, modals, toolbars, tables, buttons, badges, placeholders, and error messages MUST BE IN ENGLISH (Official Cambridge IELTS Academic Standard).
- No Vietnamese language strings on any user-facing frontend components or templates.

## Code Standards
- Frontend: React 18 / 19, TypeScript, Tailwind CSS, Lucide icons, TanStack React Table.
- Backend: .NET 8, Clean Architecture, MediatR, Entity Framework Core, SQL Server / Postgres, Qdrant.
- Design: Modern EdTech Standard (80/20 Rule - 20% Red/Black/White Brand Chrome, 80% Harmonized 4-Skill Content).
